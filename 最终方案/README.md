# 最终方案汇总入口

本目录由创建者的 agent 维护。当前只有协作结构，尚未生成业务最终稿或实测结论。

## 每次汇总

1. 同步仓库并记下本次读取的提交版本，读取 `公共资料/测试方案.md`。
2. 阅读 `创建者/交接.md`、`Awei/交接.md` 的“已完成，可汇总”。
3. 打开列出的原文件和证据，按当前方案的阶段与测试编号整理；不要仅根据交接摘要宣告成功。
4. 将采用内容写入 `完整方案.md`，必要的最终执行文件整理至 `执行材料/`。每节或每份材料写明来源路径与提交版本。
5. 区分设计预期、实测结果与待确认事项，保留失败和未测。缺失材料或矛盾列在最终稿的“待确认”部分，反馈到创建者自己的交接。
6. 创建者自己的 `交接.md` 中记录本次采用哪些文件、输出位置及遗留问题，不修改对方交接或原始证据。

按需生成 `完整方案.md`、`拍摄执行表.md` 等文件，不预建虚假的完成稿。方案内的模拟业务结果不等于产品实测成功。

可直接给创建者 agent 的指令：

> 先读取根 AGENTS.md、公共测试方案及双方交接，只汇总“已完成，可汇总”的材料。核对实际文件与证据，按方案阶段和任务编号更新最终方案及执行材料，保留来源路径与提交版本，明确未测和待确认项，并在创建者交接中反馈本次采用内容与遗留问题。
